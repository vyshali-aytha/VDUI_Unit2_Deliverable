# VDUI_Unit2_Deliverable

This repository contains the completed activities for **PPT 1, PPT 4, PPT 5, and PPT 7** of the Data Visualization and User Interface (VDUI) course.

## Activities Covered

- **PPT 1** – Advanced visualization techniques, interaction, coordinated views, anomaly detection, Table Lens, and dashboard design
- **PPT 4** – Dimensionality reduction using PCA, t-SNE, and UMAP, correlation analysis, and visualization of high-dimensional data
- **PPT 5** – Choropleth maps, SHAP explanations, uncertainty visualization, and coordinated multiple views
- **PPT 7** – Visual hierarchy, accessibility, axis design, ethical annotations, and visualization review

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Scikit-learn
- SHAP
- UMAP
- Google Colab
